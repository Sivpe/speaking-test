How Muse scoring works

There is no API key in this version. Muse (in chat) is the scorer — scoring is done by Muse in chat, not instantly in this page.

  1. Download package for Muse — in the Attempts list below, download the package file for one finished attempt. Or, for a whole class, use Download all waiting packages (one file) below — one file with every waiting student's package inside it.
  2. Send it to Muse in chat — attach that one file to a message to Muse and ask for the scores. Muse listens to every answer and sends back one scores file — for a batch, one batch scores file for the whole class.
  3. Import Muse scores — use the button below (or in Results) and pick the scores file Muse gave you. One import works for a single student or for the whole class batch. The page works out each final score in that test's score mode, and students can see them in Results.

Attempts — send to Muse

Every finished attempt on this device. For one student, download their package. For a whole class, download all waiting packages as one file, send that one file to Muse in chat, then import the one batch scores file Muse returns.

Attempts missing? If you still have the students' package files, tap Restore attempts and choose them — you can choose all of them at once, or one batch package file. The attempts come back here, then import Muse's scores file again and every result appears.

Use in Chrome (outside Muse)

Recording works best when this page is the top page in Chrome. Download one file with your tests inside it, then open that file in Chrome on any computer or phone. No API key is needed anywhere — Muse scores in chat.

The downloaded file contains your tests only — not saved attempts, recordings, packages or results. Attempts and results stay saved on this device only, in this browser.

The scoring loop

  1. Student records answers in this page.
  2. Teacher downloads the attempt's package for Muse (Teacher tab) and sends the file to Muse in chat.
  3. Muse listens and returns a scores file; teacher imports it — the student's score and feedback appear in Results.
